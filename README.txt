# BIOMEDICINA 2026-2 — site estático

Arquivos:
- index.html
- styles.css
- app.js
- biomedicina-2026-2.json

## Publicação
Envie os quatro arquivos para a mesma pasta em uma hospedagem estática.

## WordPress
Depois que o site estiver publicado em uma URL, use um bloco HTML personalizado:

<iframe
  src="URL-DO-GERADOR/"
  width="100%"
  height="2200"
  style="border:0;width:100%;"
  loading="lazy">
</iframe>

## Atualização de semestre
Mantenha o app.js e styles.css. Atualize o JSON e, se necessário, ajuste o nome do arquivo JSON referenciado em app.js.
